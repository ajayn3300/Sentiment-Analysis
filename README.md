# Sentiment Analysis

[![Jupyter Notebook](https://img.shields.io/badge/Notebook-SentimentAnalysis-orange)](SentimentAnalysis.ipynb)

A sentiment analysis project using **BERT fine-tuning** on a provided dataset (`train.csv`). This repository contains the end-to-end workflow for training a model to classify text sentiment.

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `SentimentAnalysis.ipynb` | Main Jupyter notebook with BERT fine-tuning implementation |
| `train.csv` | Training dataset used for feature engineering and model training |
